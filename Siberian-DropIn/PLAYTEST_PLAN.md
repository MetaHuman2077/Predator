# План живых плейтестов SurvivalSimBot (задачи 3–4)

**Статус: НЕ ВЫПОЛНЕНО — требует запущенного Unity Editor.** Плейтесты запускаются только
на машине с проектом (`D:\Unity\Unity Projects\Siberian`). Телеметрия ниже не сфабрикована
и появится только после реального прогона.

## Протокол (3 партии + 5 партий = 8 отчётов)

Перед запуском:
1. Применить фиксы компиляции: `powershell -ExecutionPolicy Bypass -File Siberian-DropIn\Tools\fix_autoplaytester.ps1`, убедиться, что консоль чистая.
2. Убедиться, что MCP-мост поднят (лог `[Siberian MCP] Мост запущен...`), Claude Code подключён: `claude mcp add unity --transport http http://127.0.0.1:8080/mcp`.
3. НЕ править код во время серии — перекомпиляция выбивает Play Mode и портит серию.

Серия 1 (партии 1–3) — базовая линия ДО внедрения фич из Siberian-DropIn.
Серия 2 (партии 4–8) — ПОСЛЕ внедрения (pursuit-AI, first-fall grace, cold audio, палитра).
Так разница в телеметрии станет аргументом «фичи сработали / нет», а не шумом.

## Телеметрия на каждую партию (обязательные поля отчёта)

| Поле | Источник |
| --- | --- |
| Время жизни / время до победы, с | SurvivalSimBot (таймаут эпизода 600 игровых с) |
| Провалы под лёд (кол-во, зона D) | ThinIce |
| Погиб ли от первого провала | новое поле — проверка first-fall grace |
| Встречи с волком (входы в chaseRange 15м) | WolfAI |
| Укусы получено / урон суммарно | WolfAI (−15 тепла / −20 энергии за укус) |
| Достиг вышки? Канистры 3/3? | счётчик генератора |
| minWarmth за партию | SurvivalStats (базовая линия по боту: 52) |
| Срабатывания экстренного обогрева бота (порог 38) | SurvivalSimBot — помечать как эвристику БОТА, не механику игры |
| Время переходов между зонами A→B→C→D/E→F | метрика темпа, Roadmap №10 |

## Что считать сигналом к правке (гипотезы для отчёта по задаче 4)

- Если бот по-прежнему 10/10 побед и minWarmth ≥ 52 — игра, вероятно, слишком мягкая для
  бота; решает только человеческий плейтест (бот ≠ человек, см. «Сводный анализ» §5).
- Если после pursuit-AI число укусов заметно выросло — проверить, не стал ли волк
  несправедливо силён (упреждение против бота, бегущего по прямой, почти идеально).
- Если первый провал перестал убивать, но partии всё равно кончаются смертью на льду —
  смотреть на ВТОРОЙ провал: возможно, нужен кулдаун неуязвимости после выбирания.
- Свести время переходов A→F в Метрики v0.2 (лист темпа) и сверить с ожидаемым
  пейсингом сжатие→разрядка→риск→подъём.
